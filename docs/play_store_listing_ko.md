## 4. 스크린샷 촬영 체크리스트

### 필수 규격
- **Phone:** 최소 2장, 권장 4~8장
- 해상도: 최소 320px, 최대 3,840px (비율 16:9 또는 9:16 권장)
- 형식: PNG 또는 JPEG, 최대 8MB

### 촬영 화면 목록 (권장 순서)

| 순서 | 화면 | 촬영 포인트 |
|------|------|------------|
| 1 | **홈 화면** | 5가지 도구 카드 전체 보이도록 |
| 2 | **일반 계산기** | 숫자와 연산자가 입력된 상태 (예: 1,234 × 56) |
| 3 | **공학용 계산기** | sin/cos 버튼 + 수식 입력 + 실시간 결과 표시 |
| 4 | **단위 변환기** | 길이 탭 + 변환 결과 전체 목록 표시 |
| 5 | **퍼센트/할인 계산기** | 할인 탭 + 계산 결과 표시 |
| 6 | **날짜 계산기** | D-Day 탭 + 카운트다운 숫자 크게 표시 |
| 7 | **설정 화면** | 전체 설정 항목 목록 |

### 촬영 전 체크사항
- [ ] 상태바 시간: 9:41 (Google 권장 시간)
- [ ] 배터리 아이콘: 100% 충전 상태
- [ ] 알림 없음 (방해 금지 모드 활성화)
- [ ] 다크모드 OFF (라이트 테마로 통일)
- [ ] 실제 계산값 입력 후 결과 표시 상태로 촬영
- [ ] 광고 배너 표시되는 상태로 촬영 (실제 앱 모습 반영)

### 그래픽 에셋 (선택사항이지만 권장)
- **Feature Graphic:** 1,024 × 500 px (스토어 상단 배너)
  - 앱 아이콘 + 앱 이름 + 한 줄 소개 텍스트 구성 권장

## 6. 데이터 보안 섹션 답변 가이드

Play Console → 앱 콘텐츠 → 데이터 보안

### 핵심 원칙
> 앱 자체는 데이터를 수집/공유하지 않지만,  
> **Google AdMob SDK**가 광고 목적으로 일부 데이터를 처리합니다.

---

### 섹션별 답변

#### ① 데이터 수집 여부
```
앱이 사용자 데이터를 수집하거나 앱 밖으로 공유합니까?
→ 예 (AdMob에 의해 수집됨을 선택)
```

#### ② 수집되는 데이터 유형

| 데이터 유형 | 수집 | 공유 | 처리 주체 | 필수 여부 |
|------------|------|------|----------|----------|
| 기기 또는 기타 ID (광고 ID) | ✅ | ✅ | Google AdMob | 광고 목적 |
| 앱 활동 (앱 상호작용) | ✅ | ✅ | Google AdMob | 광고 분석 |
| 앱 정보 및 성능 (비정상 종료 로그) | ✅ | ❌ | Google AdMob | 선택 |

> 이름, 이메일, 전화번호, 위치, 연락처, 사진 등은 **수집하지 않음**으로 선택

#### ③ 데이터 암호화 전송 여부
```
전송 중 데이터가 암호화됩니까?
→ 예 (AdMob은 HTTPS 사용)
```

#### ④ 데이터 삭제 요청 가능 여부
```
사용자가 데이터 삭제를 요청할 수 있습니까?
→ 아니요 (앱이 직접 수집하는 데이터 없음)
  단, Android 설정에서 광고 ID 재설정 가능하다고 안내 가능
```
